# REINVENT4 Mol2Mol dock-first Pareto (new)

Same iterative workflow as `iterative_dock_pareto`; REINVENT4 Mol2Mol replaces GenMol and samples analogs of each current Pareto parent. It needs REINVENT4 installed plus a Mol2Mol prior. Set `REINVENT`/`REINVENT_MOL2MOL_PRIOR` or pass `--reinvent-executable`/`--reinvent-model`; choose `--reinvent-device` and `--generator-max-output`. The conditional prior and multinomial/beam-search sampling give similarity and diversity controls; sampling emits one result per requested molecule count and can use CPU, with an expected runtime cost versus a lightweight fragment mutation. See [official sampling docs](https://github.com/MolecularAI/REINVENT4/blob/main/configs/sampling.toml) and [Mol2Mol concepts](https://github.com/MolecularAI/REINVENT4/blob/main/contrib/reinvent-doc/core_concept/README.md).
